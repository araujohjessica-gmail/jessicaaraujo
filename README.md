## 🚀 Featured Project

### Excursions Platform
Full-stack platform for selling bus trips to festivals, concerts, Carnival and New Year's events — with checkout, payments, a customer area and a complete admin dashboard.

**[🔗 Live Demo](https://excursoes-portfolio.vercel.app)** · **[Frontend](https://github.com/araujohjessica/excursoes-portfolio)** · **[API](https://github.com/araujohjessica/excursoes-api)**

- 💳 Payments with **Asaas** (Pix with QR Code, bank slip and installment credit card)
- 🔐 Secure webhook validation, JWT authentication and passwordless customer login
- ⚡ Real-time messaging and presence over **WebSocket**
- ⏱️ Background jobs for payment sync and automatic expiration of unpaid bookings
- 🛠️ Admin dashboard: trips, bookings, finance, reviews and customer messages
- 🧪 Demo mode with a simulated backend — runs in the browser with no server

`React` `TypeScript` `Vite` `Tailwind CSS` `Node.js` `Express` `SQLite` `WebSocket` `JWT`

> Try the admin panel: open the demo, go to `/#/admin/login` and sign in with any email and password.

### Online Scheduling System
Booking platform for independent professionals (clinics, therapists, tutors): public booking page, passwordless client area, professional dashboard and full financial control.

**[🔗 Live Demo](https://agenda-eta-three.vercel.app)** · **[Frontend](https://github.com/araujohjessica/agenda)** · **[API](https://github.com/araujohjessica/agenda-api)**

- 📅 Availability periods that generate time slots automatically
- 🔒 Business rules enforced server-side: minimum notice, cancellation window, no double booking
- ✉️ Passwordless login via email code, email notifications and `.ics` calendar files
- 💰 Finance dashboard: revenue, receivables, expenses, 12-month trends and CSV export
- ✅ **110 end-to-end tests** running on GitHub Actions

`React 19` `TypeScript` `Tailwind CSS` `Node.js` `Express` `SQLite` `JWT`
